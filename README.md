## About the Project

E-Learning Platform is a web-based application
that provides an interactive online learning
experience.

## Objectives

- Make learning accessible online.
- Organize educational resources.
- Provide a user-friendly learning interface.

## Future Enhancements

- Interactive quizzes
- Course progress tracking
- Improved learning dashboard

- ## Getting Started

### Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Install the dependencies:

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
